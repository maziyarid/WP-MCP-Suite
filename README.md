# WP-MCP-Suite-
WP MCP Suite is a modular WordPress plugin unifying: WordPress content, a Word/OneDrive editorial mirror, Excel-based reporting, SEO metadata (Rank Math/Yoast), Search Console, GA4, Microsoft Clarity, Uptime Robot, backlink/internal-link intelligence, AI-assisted drafting, encrypted database backups, and a Copilot-ready consolidated data export.
